Perguntas frequentes

Tem dúvidas?

O que acontece ao fim dos 14 dias? +
A app bloqueia o acesso a novos registos, mas os seus dados ficam todos guardados. Pode activar uma licença a qualquer momento para continuar. Os registos feitos durante o trial não se perdem.
Os dados ficam guardados onde? +
Localmente no dispositivo. Opcionalmente pode activar a sincronização com o GitHub (gratuito) para ter cópia de segurança e aceder de vários dispositivos.
Posso usar em vários dispositivos? +
Sim. Com a sincronização GitHub, todos os dispositivos do restaurante partilham os mesmos registos. Uma licença cobre o NIF do estabelecimento — não é por dispositivo.
Cumpre as normas legais portuguesas? +
Sim. Conforme com o Regulamento (CE) n.º 852/2004, Reg. CE 178/2002, Dec.-Lei 106/2005 e as directrizes da ASAE e DGAV. Os relatórios PDF incluem as referências legais necessárias.
Qual é o preço após o trial? +
Plano mensal a partir de €9,90/mês. Planos trimestrais, semestrais e anuais com desconto disponíveis. Uma licença por NIF — sem limite de utilizadores ou dispositivos.
