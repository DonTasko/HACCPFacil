Política de Privacidade

Última actualização: Setembro de 2026  ·  HACCP Pro — L.Apps Studio

📋 Resumo simples: Recolhemos apenas os dados necessários para prestar o serviço. Os dados ficam guardados localmente no seu dispositivo e, opcionalmente, num repositório GitHub privado que controla. Não vendemos dados a terceiros nem utilizamos publicidade.

1. Responsável pelo Tratamento de Dados

O responsável pelo tratamento dos dados pessoais recolhidos através da aplicação HACCP Pro e do site haccpdigital.online é:

  • Entidade: L.Apps Studio
  • Contacto: suporte@haccpdigital.online
  • País: Portugal

2. Dados Recolhidos

2.1 Dados do Estabelecimento

Para a utilização da aplicação, recolhemos os seguintes dados do estabelecimento:

  • Nome do estabelecimento e NIF
  • Morada e contactos (telefone e email)
  • Nome do responsável HACCP
  • Nome do consultor ou empresa de consultoria (opcional)

2.2 Dados Operacionais HACCP

A aplicação recolhe registos operacionais introduzidos pelo utilizador:

  • Registos de temperaturas, limpezas, óleos, validades e recepções
  • Não conformidades (incluindo fotografias opcionais)
  • Check-lists semanais e registos de confecção
  • Nomes dos colaboradores associados a cada registo

2.3 Dados de Contacto (Formulário de Interesse)

Se submeter o formulário de interesse no nosso site, recolhemos o nome do estabelecimento, endereço de email e telefone (opcional), exclusivamente para envio de informações sobre a disponibilidade da aplicação.

2.4 Dados Técnicos

A aplicação não recolhe dados de telemetria, localização GPS, nem efectua rastreamento de comportamento.

3. Finalidade e Base Legal

Os dados são tratados com base nas seguintes finalidades e fundamentos legais (Artigo 6.º do RGPD):

  • Execução do contrato — prestação do serviço HACCP Pro, gestão da licença e envio de relatórios
  • Interesse legítimo — suporte técnico e melhoria do serviço
  • Consentimento — envio de comunicações de marketing, quando aplicável
  • Obrigação legal — cumprimento de obrigações fiscais e legais

4. Onde São Guardados os Dados

4.1 Armazenamento local

Todos os registos HACCP ficam guardados localmente no dispositivo do utilizador através de localStorage do browser/aplicação. Estes dados não são transmitidos automaticamente para nenhum servidor externo.

4.2 Sincronização opcional com GitHub

Se o utilizador configurar a sincronização, os dados são enviados para um repositório privado do GitHub, identificado pelo NIF do estabelecimento. O repositório é gerido pela L.Apps Studio e o acesso é restrito. O GitHub (Microsoft) actua como subprocessador. Para mais informações: Política de Privacidade do GitHub.

4.3 Envio de emails

O envio de alertas e relatórios por email é efectuado através do serviço Resend (Resend Inc., EUA). Os emails contêm dados operacionais do estabelecimento. Para mais informações: Política de Privacidade do Resend.

4.4 Infraestrutura do serviço

O servidor intermediário que processa pedidos de sincronização está alojado na Cloudflare (Cloudflare Inc., EUA). Os dados são processados em trânsito mas não são armazenados no servidor. Para mais informações: Política de Privacidade da Cloudflare.

5. Prazo de Conservação

  • Dados locais: Conservados enquanto o utilizador não os eliminar do dispositivo
  • Dados no GitHub: Conservados enquanto o utilizador mantiver a sincronização activa. Podem ser eliminados a pedido
  • Dados do formulário de interesse: Eliminados após 12 meses ou após solicitação
  • Dados de faturação: Conservados pelo prazo legal de 10 anos (obrigação fiscal)

6. Direitos do Titular dos Dados

Ao abrigo do RGPD, o utilizador tem os seguintes direitos:

  • Acesso — saber quais dados guardamos sobre si
  • Rectificação — corrigir dados incorrectos
  • Eliminação — solicitar a eliminação dos seus dados ("direito ao esquecimento")
  • Portabilidade — receber os seus dados em formato exportável (disponível na aplicação via Exportar → JSON)
  • Oposição — opor-se ao tratamento com base em interesse legítimo
  • Limitação — solicitar a limitação do tratamento em determinadas circunstâncias

Para exercer qualquer destes direitos, contacte: privacidade@haccpdigital.online. Responderemos no prazo máximo de 30 dias.

Tem também o direito de apresentar reclamação à CNPD (Comissão Nacional de Protecção de Dados): www.cnpd.pt.

7. Transferências Internacionais de Dados

Os subprocessadores GitHub, Resend e Cloudflare estão sediados nos EUA. As transferências são efectuadas ao abrigo de Cláusulas Contratuais Padrão aprovadas pela Comissão Europeia ou ao abrigo do Data Privacy Framework UE-EUA.

8. Cookies

O site haccpdigital.online não utiliza cookies de rastreamento ou publicidade. A aplicação utiliza localStorage para guardar dados operacionais e preferências do utilizador — não são cookies de terceiros.

9. Segurança

Adoptamos medidas técnicas e organizativas adequadas para proteger os dados pessoais contra acesso não autorizado, perda ou destruição, incluindo:

  • Comunicações cifradas via HTTPS/TLS
  • Repositórios GitHub privados com acesso restrito
  • Tokens de autenticação com permissões mínimas necessárias
  • Chaves de licença com validação criptográfica

10. Menores

A aplicação HACCP Pro destina-se a profissionais do sector alimentar. Não recolhemos intencionalmente dados de menores de 18 anos. Se tomar conhecimento de que dados de menores foram fornecidos sem consentimento, contacte-nos para eliminação imediata.

11. Alterações a Esta Política

Reservamo-nos o direito de actualizar esta Política de Privacidade. Alterações materiais serão comunicadas por email (se o utilizador tiver fornecido um endereço) ou através de aviso na aplicação com antecedência mínima de 30 dias.
